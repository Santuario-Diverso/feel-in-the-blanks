# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in My Santuario Diverso, please do not report it through public issues. 

Instead, please send an email to the repository maintainers. We will respond as quickly as possible, usually within 48 hours, to acknowledge the receipt of your vulnerability report and outline the next steps.

## Supported Versions

Currently, only the main branch (latest release) is supported with security updates.

## Best Practices
Since this platform handles sensitive community data, any self-hosted deployment must ensure that data is encrypted at rest and in transit, and that database access is strictly role-based.
