# Contributing to My Santuario Diverso

We welcome contributions to this open-source civic infrastructure project. 

## Developer Certificate of Origin (DCO)

To ensure that all contributions are properly licensed and that contributors have the right to submit the code, we require all commits to be signed off under the Developer Certificate of Origin (DCO) 1.1. We do not use a Contributor License Agreement (CLA).

By adding a `Signed-off-by` line to your commit messages, you certify that you wrote the patch or have the right to contribute it under the open-source license (EUPL-1.2).

Example:
`Signed-off-by: Jane Doe <jane.doe@example.com>`

You can easily do this by using the `-s` flag with `git commit`:
`git commit -s -m "Your commit message"`
